# Sree Vijayalakshmi Enterprises website

Static website starter using plain HTML, CSS, and JavaScript. No installation or build is required.

## Structure

```text
website sve/
  index.html            Homepage, company details, services, contact
  assets/
    css/styles.css      Responsive styles
    js/main.js          Small browser enhancements
    images/             Place approved logo and event photographs here
  .gitignore
  .nojekyll
  README.md
```

## Preview and edit

Open `index.html` in a browser. Edit the content in that file and the styles in `assets/css/styles.css`. Relative asset paths allow this starter to run locally or under a hosted project path.

Company copy and contact details come from the supplied introduction letter. Confirm current contact details before launch. The email button opens the visitor's email app; it does not submit or store a form.

## Remaining launch work

- Add the approved company logo and actual event photographs.
- Confirm which telephone number supports WhatsApp before adding that link.
- Add a form service if a submitted enquiry form is required.
- Select a hosting provider and check its commercial-use terms before deployment.
- Optionally purchase and connect a custom domain.

Repository: https://github.com/GokulKrishna005/website-sve

The website files belong at the repository root. Uploading source files does not deploy the website; hosting still needs to be configured.
